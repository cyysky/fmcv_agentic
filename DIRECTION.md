# Direction (human)

1. **Agents can save binary files** — add a tool that lets agents save binary content (downloaded PDFs, images, archives, etc.) to the workspace/channel folder, not just text. When an agent fetches a URL that returns binary data (e.g. a .pdf, .png, .zip), it should be able to save the actual binary file (base64 or streamed) instead of falling back to saving extracted text as .md. Reference: in #fmcv on 2026-08-09 the agent downloaded the EGGROLL paper PDF (https://eshyperscale.github.io/imgs/paper.pdf) but could not save the binary — "The PDF is a binary (can't be saved directly by channel tools)" — and had to save the extracted text to fmcv/papers/EGGROLL_evolution_strategies_at_the_hyperscale.md instead.
